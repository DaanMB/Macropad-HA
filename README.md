<p>I made this project to control parts of my pc with a macropad and my conclusion was that the things i wanted to do with a macropad where best achevable with espHome. The only problem with using espHome is that somtimes the buttons ghost press or double press, i dont know if thats a skill isue of me or espHome.</p>
<h2>Features</h2>
<p>
  1. 4x4 buttons that are programmable in HA. <br>
  2. An 128X64 oled screen that displays time and whats playing on spotify using a HA spotify intergration. <br>
  3. 2 rgb leds that are programmable in HA. <br>
  4. 2 potentiometers that are programmable in HA</p>
